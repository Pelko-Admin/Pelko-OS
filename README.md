#PELKO OS
Pelko OS
Pelko OS is a custom Linux distribution built on top of Linux Mint, designed to provide specialized, out-of-the-box environments for specific workflows. By leveraging the rock-solid stability and user-friendliness of Linux Mint, Pelko OS eliminates setup friction and optimizes the desktop experience for creators, gamers, and security enthusiasts.

⚠️ Project Status: Pelko OS is currently in active development. The primary focus is the Editing Edition, with additional editions planned for future releases.

🎯 Distro Vision & Editions
Instead of a one-size-fits-all approach, Pelko OS is developed in specialized editions built upon a shared, stable core:

1. 🎬 Pelko OS — Editing Edition (Current Focus)
Engineered for digital artists, video editors, and audio producers.

Optimized Audio/Video Pipelines: Configured with low-latency kernel options and PipeWire integration for low-latency audio handling.

Pre-configured Software Suite: Essential open-source tools ready on first boot (video editing, 3D rendering, vector graphics, and audio production).

Hardware Acceleration: Tailored support for GPU workloads, including pre-configured NVIDIA CUDA and NVENC/NVDEC driver optimizations.

2. 🎮 Pelko OS — Gaming Edition (Planned)
Optimized kernel settings for high-framerate stability.

Integrated gaming platforms (Steam, Heroic, Lutris) and performance monitoring tools out of the box.

3. 🛡️ Pelko OS — Security Edition (Planned)
Curated selection of network analysis, privacy, and security tools for pentesting and system auditing.

✨ Key Features (Editing Edition)
Linux Mint Core: Inherits the stability, familiar desktop interface, and extensive Ubuntu/Debian package ecosystem.

Streamlined Workflows: Reduces post-installation setup time by including necessary multimedia codecs and drivers out-of-the-box.

System Responsiveness: Tweaked background services and performance profiles aimed at maintaining UI smoothness during heavy rendering tasks.

🛠️ System Requirements (Target Minimum)
CPU: 64-bit dual-core processor (Quad-core recommended for video rendering)

RAM: 8 GB minimum (16 GB or more recommended for 4K video editing)

Storage: 30 GB available space (SSD strongly recommended)

GPU: Dedicated NVIDIA or AMD GPU recommended for hardware-accelerated workflows

🚀 Getting Started
Since Pelko OS is in its early stages, live ISO images and build scripts will be uploaded as stable milestones are reached.

Check the Releases tab for experimental ISO builds.

Flash the ISO to a USB drive using tools like Ventoy or BalenaEtcher.

Boot in Live mode to test hardware compatibility before installing.
